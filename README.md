# 🏥 Insurance Charge Prediction

A beginner-level Machine Learning project that predicts **medical insurance charges** based on demographic and lifestyle-related features.

This project was built as part of my Machine Learning learning journey to practice the complete basic workflow — from understanding and exploring the dataset to preprocessing, model training, and prediction.

## 📌 Project Overview

The objective of this project is to predict an individual's medical insurance charges using features such as:

* Age
* Sex
* BMI
* Number of children
* Smoking status
* Region

A **Linear Regression** model is used as the initial baseline model.

> 🚧 **Project Status:** Learning / In Progress
> This is currently a basic Machine Learning project. More models, feature engineering, optimization, and deployment will be added as I continue learning.

---

## 📊 Dataset

The dataset contains information about individuals along with their medical insurance charges.

### Features

| Feature    | Description                                 |
| ---------- | ------------------------------------------- |
| `age`      | Age of the individual                       |
| `sex`      | Gender                                      |
| `bmi`      | Body Mass Index                             |
| `children` | Number of children                          |
| `smoker`   | Smoking status                              |
| `region`   | Residential region                          |
| `charges`  | Medical insurance charges — Target variable |
